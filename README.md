# FlexBlog – HTML e CSS

Este repositório contém o projeto FlexBlog, um site desenvolvido com HTML e CSS durante o curso de CSS Flexbox da **Origamid**. O projeto tem como objetivo aprimorar os conhecimentos em desenvolvimento web, com foco na utilização do Flexbox para criar layouts flexíveis, organizados e responsivos.

O desenvolvimento foi realizado para fins educacionais e de prática, permitindo explorar diferentes possibilidades de posicionamento e distribuição de elementos utilizando CSS.

## Funcionalidades

- **Estrutura HTML:** Organização do conteúdo da página utilizando elementos HTML.
- **CSS Flexbox:** Aplicação de propriedades Flexbox para alinhamento, distribuição e organização dos elementos.
- **Layout Responsivo:** Adaptação da estrutura da página a diferentes tamanhos de tela.
- **Organização Visual:** Distribuição de seções, textos, imagens e componentes para criar uma interface consistente.
- **Estilização com CSS:** Utilização de cores, tipografia, espaçamentos e outros recursos visuais.

## Objetivo do Projeto

O projeto foi desenvolvido com a finalidade de consolidar conhecimentos em CSS Flexbox, praticando conceitos fundamentais de alinhamento, dimensionamento, direção e distribuição de elementos. Também busca aprimorar as habilidades na construção de layouts para páginas web.

## Tecnologias Utilizadas

- **HTML5:** Estruturação e organização do conteúdo da página.
- **CSS3:** Estilização dos elementos e construção dos layouts utilizando Flexbox.

## Como Executar

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto.
3. Localize o arquivo `index.html`.
4. Abra o arquivo em um navegador para visualizar o site.

## Aprendizados

Durante o desenvolvimento, foram praticadas propriedades como `display: flex`, `flex-direction`, `flex-wrap`, `justify-content`, `align-items`, `align-content`, `flex`, além da criação de layouts flexíveis e responsivos.

## Referência e Créditos

O projeto foi desenvolvido durante o curso de CSS Flexbox da **Origamid**, com finalidade educacional e de aprimoramento das habilidades em HTML e CSS. A atividade teve como foco a prática dos conceitos apresentados ao longo do curso.
